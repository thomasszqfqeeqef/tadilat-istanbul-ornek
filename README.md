# Yeni Yuva Tadilat : site exemple

Site vitrine d'exemple pour une entreprise de renovation interieure a Istanbul (en turc). Nom, telephone et adresses sont fictifs.

- Un seul fichier : index.html, sans dependance.
- Pour l'adapter a un client, modifier le bloc window.SITE en haut du fichier.
- Les images avant/apres sont generees par IA, a remplacer par les vraies photos du client.
